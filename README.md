# Pricing Demo App

A demo pricing page built with Next.js (App Router) and TypeScript. It shows three subscription tiers — Starter, Pro, and Team — with a monthly/annual billing toggle.

## Known Issue

When switching to annual billing, the displayed prices appear unexpectedly low.

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Running Tests

```bash
npm test
```

## Deploying to Vercel

Push this repository to GitHub, then import it on [vercel.com](https://vercel.com). No additional configuration is required.
